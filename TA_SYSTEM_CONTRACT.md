# T+A system contract

Declared 2026-09-14 before any new candidate outcomes. Design B: explicit role-specific perception.

## Established facts
The current source implements frozen B/adaptive/1337 contextual MELD7 state and separately namespaced frozen D2/1337 CREMA6 listener evidence. One WavLM execution supplies both. Historical categorical integrations and later acoustic replacements were rejected; no such candidate is accepted here. Former RAVDESS confirmation is consumed, despite older immutable manifests saying pending. The authoritative saved source and asset bytes must be checked independently of reports.

## Choices for this continuation
`meld_state` remains authoritative for MELD categorical consumers and calibration. It uses current transcript, at most three preceding observed human turns, and B's existing bounded acoustic correction. D2 never replaces or renormalizes this field. `acoustic_evidence` is authoritative only as an estimate of the separate six-category audio-listener target, with a normalized 128-dimensional representation, availability, and provenance. It is not a diagnosis or a claim about a person's true internal state.

`response` is the authoritative proposed user-facing action. A prospectively specified deterministic policy may consume both estimates and choose a distinct authored conversational offer when supported vocal evidence warrants it. The historical B response remains visible as the reference action. Merely exposing fields does not pass the interaction requirement. The exact response routes, thresholds, eligible classes, fixed cases, controls, useful effect, and safeguards must be frozen in HYPOTHESIS_01.md before candidate evaluation. If they fail, retain B's response and label the result evidence-only.

MELD7 labels and evaluation remain categorical source annotations. D2 remains supervised by approved CREMA-D training listener votes, and evaluated on matching six-class targets in existing source/used-working evidence. Calm/none are not silently relabeled, surprise is not appended as zero, and unsupported classes receive no new D2-derived response route. Disagreement must remain explicit; contextual and vocal estimates can disagree without either becoming observed fact. Low confidence, unavailable evidence, and unsupported categories retain the existing authored policy. Missing/corrupt/over-60-second audio retains calibrated text fallback; decoded long audio remains valid but ineligible. Silence is valid input and is not forced neutral.

This is an utterance-final local transcript-plus-waveform system with incremental PCM input, not streaming WavLM or ASR. Transcript contents are inert user data. Context contains only real observed human turns. Inferred state and authored actions never feed back as observed history.

## Release claim and limits
A successful role-specific candidate may claim reproducible contextual state plus a measured, evidence-dependent deterministic response route on disclosed development cases. It cannot claim that delivery-sensitive integrated MELD classification, human response usefulness, independent transfer, selective nuisance robustness, or official-test performance is solved. Historical class weaknesses and failed repeat tails remain visible. The release requires full local waveform-to-state-to-response execution, strict asset/source identity, no stale evidence, causal history, and fewer than six billion required learned parameters.

No new backbone training, extension, corpus acquisition, test/confirmation inference, human pilot, remote upload, publication, or push is part of this continuation. Future consumers may depend on named state/evidence/action fields, availability and provenance, but cannot treat estimates as observed history or merge namespaces without a newly evaluated contract.
